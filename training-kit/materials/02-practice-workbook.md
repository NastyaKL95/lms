## Шаблон 4. Чек-лист правовой проверки (РФ)

Отметьте «Да/Нет»:

1. У каждого заимствованного материала проверены права использования  
2. Лицензии и атрибуция корректно указаны  
3. Публикуемый контент не нарушает авторские права третьих лиц  
4. Данные обучающихся собираются только по необходимой цели  
5. Есть правовое основание обработки ПДн (согласие/договор/иной механизм)  
6. Настроены роли доступа к ПДн и оценочным данным  
7. Обеспечена доступность ресурса для обучающихся с ОВЗ  
8. Ресурс соответствует локальным актам организации

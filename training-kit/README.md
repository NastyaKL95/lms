# Комплект учебных материалов по курсу

Этот комплект подготовлен на основе тем из файла:
`Основы проектирования цифровых образовательных ресурсов.docx`.

## Что внутри

- `slides/01-cdo-basics-legal-rf.md` — презентация по теме 1
- `slides/02-edtech-trends-platforms.md` — презентация по теме 2
- `slides/03-lms-moodle.md` — презентация по теме 3
- `slides/04-information-systems-design.md` — презентация по теме 4
- `materials/01-instructor-guide.md` — сценарии проведения занятий
- `materials/02-practice-workbook.md` — рабочая тетрадь для практик
- `materials/03-assessment-bank.md` — банк оценочных средств (тесты + рубрики)
- `materials/04-legal-memo-rf.md` — правовая памятка (РФ)
- `materials/05-visual-style-guide.md` — визуальный гайд по современному оформлению

## Формат презентаций

Презентации оформлены как Markdown-слайды (совместимы с Marp/Reveal и легко переносятся в PowerPoint/Google Slides):

- каждый блок между `---` — отдельный слайд;
- структура уже готова под визуально современную подачу: короткие тезисы, таблицы, блоки с активностями;
- можно добавлять иллюстрации, иконки и скриншоты LMS без изменения логики подачи.

## Рекомендации по проведению

1. Используйте `01-instructor-guide.md` как базовый сценарий пары.
2. Раздавайте шаблоны из `02-practice-workbook.md` перед практикой.
3. Для текущего контроля применяйте тесты и рубрики из `03-assessment-bank.md`.
4. При обсуждении авторского права, персональных данных и доступности опирайтесь на `04-legal-memo-rf.md`.

## Важно по правовым аспектам

Материалы ссылаются на законодательство РФ (актуальные редакции нужно перепроверять перед занятием):  
ГК РФ (ч. IV), 273-ФЗ, 149-ФЗ, 152-ФЗ, 181-ФЗ, 436-ФЗ, действующие требования СанПиН и локальные акты образовательной организации.

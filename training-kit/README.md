# Комплект учебных материалов по курсу

Этот комплект подготовлен на основе тем из файла:
`Основы проектирования цифровых образовательных ресурсов.docx`.

Для занятий открывайте файлы PowerPoint и Word. Черновики в Markdown лежат рядом и нужны только как исходник.

## Презентации (PowerPoint)

- `pptx/Тема 1. Основные понятия и классификация ЦОР.pptx`
- `pptx/Тема 2. Современные тенденции в EdTech.pptx`
- `pptx/Тема 3. Системы управления обучением LMS.pptx`
- `pptx/Тема 4. Основы проектирования информационных систем.pptx`

## Материалы для проведения занятий (Word)

- `docx/Содержание комплекта.docx` — с чего начать
- `docx/Методический сценарий проведения занятий.docx` — ход пары
- `docx/Рабочая тетрадь.docx` — бланки для практики
- `docx/Банк оценочных средств.docx` — вопросы, ключи и рубрика
- `docx/Правовая памятка (РФ).docx` — нормы и чек-лист публикации
- `docx/Визуальный гайд презентаций.docx` — правила оформления слайдов

## Рекомендации по проведению

1. Откройте сценарий занятия и презентацию нужной темы.
2. Раздайте рабочую тетрадь перед практикой.
3. Для текущего контроля возьмите вопросы и рубрику из банка оценочных средств.
4. При обсуждении авторского права, персональных данных и доступности опирайтесь на правовую памятку.

## Важно по правовым аспектам

Материалы ссылаются на законодательство РФ (актуальные редакции нужно перепроверять перед занятием):  
ГК РФ (ч. IV), 273-ФЗ, 149-ФЗ, 152-ФЗ, 181-ФЗ, 436-ФЗ, действующие требования СанПиН и локальные акты образовательной организации.
